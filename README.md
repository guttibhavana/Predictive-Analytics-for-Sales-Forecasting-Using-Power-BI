# 📈 Historical Sales Trend Analysis and Forecasting

## 📌 Project Overview

This Power BI project focuses on analyzing historical sales data and forecasting future sales trends using predictive analytics. The dashboard helps identify business performance patterns, profitability trends, and future sales expectations through interactive visualizations and forecasting techniques.

---

## 🎯 Project Objectives

- Analyze historical sales performance.
- Forecast future sales trends using time-series forecasting.
- Identify profitable and less profitable sub-categories.
- Compare sales performance across different states and regions.
- Support data-driven business decision-making.

---

## 🛠️ Tools Used

- Power BI
- Power Query
- Excel
- Data Visualization
- Time-Series Forecasting

---

## 📊 Dashboard Features

### KPI Cards
- Total Sales
- Total Profit
- Total Orders

### Sales Trend Analysis
- Historical sales performance over time
- Future sales forecasting with confidence intervals

### Profit Analysis
- Profit by Sub-Category
- Identification of high-profit and low-profit products

### Geographic Analysis
- Sales by State
- Regional performance comparison

### Interactive Filters
- Region
- Ship Mode
- Sub-Category

---

## 📈 Forecasting Implementation

Power BI's built-in forecasting feature was used to:

- Analyze historical sales trends
- Detect patterns in sales performance
- Predict future sales values
- Display confidence intervals for forecast reliability

---

## 🔍 Key Insights

- Historical sales show a consistent growth trend.
- Chairs contribute the highest profit among furniture sub-categories.
- Tables generate lower profitability compared to other sub-categories.
- California contributes the highest sales revenue.
- Forecast results indicate continued sales growth in upcoming periods.
